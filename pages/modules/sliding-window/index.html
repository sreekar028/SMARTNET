Sliding Window Protocol

Flow Control · Pipelined Transmission · Window Advancement

The Sliding Window Protocol allows the sender to transmit multiple frames before needing an acknowledgment (ACK). By using a sender window size W > 1, the sender keeps the channel busy and pipelines transmission, dramatically increasing channel utilization over simple Stop-and-Wait.

Window Mechanics

• Window [S_base, S_next]: Frames inside the sender window can be sent immediately.
• Advancement: When ACK for frame k arrives, the window base shifts forward.
• Flow Control: Window size limits unacknowledged frames to protect receiver buffer.
