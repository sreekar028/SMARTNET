Distance Vector Routing

Distributed Bellman-Ford Routing · Routing Table Convergence

Distance Vector Routing (used in RIP) is a distributed algorithm where each node maintains a vector of distances to all known destinations. At every iteration, neighboring nodes exchange vectors and update their routing tables using the Bellman-Ford equation: D_x(y) = min_v { c(x,v) + D_v(y) } until network convergence is achieved.
