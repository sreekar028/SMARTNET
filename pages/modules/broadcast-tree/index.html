Broadcast Routing & Spanning Tree Theory

Preventing Broadcast Storms and Eliminating Loops in Packet Switched Networks

1. Spanning Tree Construction (BFS Traversal)

A broadcast tree is a subgraph of the network that includes every reachable vertex (node) without containing any cycles. By constructing a tree rooted at the source \(S\), each network node receives exactly one copy of the packet through its designated parent.

Tree Edges:   |E_{tree}| = |V_{reached}| - 1
Redundant Packets Avoided:   |E_{total}| - |E_{tree}|

In any connected undirected network of \(N\) nodes, a broadcast tree transmits using exactly \(N - 1\) links, eliminating redundant transmissions.

2. Broadcast Storm Mitigation & Edge Cases

  • Broadcast Storm Prevention: Flooding without a tree causes duplicate transmissions where nodes endlessly re-transmit packets back and forth, consuming all available bandwidth.
  • Cycle Pruning: Any cycle link discovered during tree traversal is pruned from forwarding, ensuring loop freedom (similar to the Spanning Tree Protocol STP IEEE 802.1D).
  • Network Partitions: When links are severed, the algorithm cleanly identifies unreachable nodes rather than assuming universal reachability.
  • Role in SMARTNET: Demonstrates root-oriented broadcast from routers (\(R_1, R_2, R_3\)), end-hosts (\(PC_1\)–\(PC_4\)), and the core Server across the centralized topology.
