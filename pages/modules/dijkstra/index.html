Dijkstra Shortest Path Routing

Link-State Routing · Shortest Path Tree · Graph Relaxation

Dijkstra's Algorithm is a fundamental link-state routing algorithm used in protocols such as OSPF. It computes the minimum-cost path from a designated source node to all destinations by iteratively visiting the unvisited node with the lowest tentative distance and relaxing its adjacent edges.

Relaxation Condition

For each neighbor v of current node u:
if (dist[u] + cost(u, v) < dist[v]) {
  dist[v] = dist[u] + cost(u, v);
  prev[v] = u;
}
