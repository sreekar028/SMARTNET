Go-Back-N ARQ Simulation

Automatic Repeat reQuest · Cumulative ACKs · Loss & Retransmission

In Go-Back-N (GBN), the sender can transmit up to N unacknowledged frames. The receiver accepts only in-order frames and discards out-of-order frames. If a frame is lost, a timeout triggers the sender to go back and retransmit all unacknowledged frames starting from the lost one.

Why Retransmit N Frames?

Because the receiver has a window size of 1 and only accepts the exact next in-order frame. Any subsequent frames that arrive out-of-order are discarded. When the sender's timeout timer expires, it must go back and retransmit all frames from the lost frame onward.
