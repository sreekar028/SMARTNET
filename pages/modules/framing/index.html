Framing Simulation

Data Link Layer · Frame Construction

Framing is a Data Link Layer technique used to divide a continuous stream of bits into manageable, identifiable frames for transmission. Each frame is delimited so the receiver can detect where one frame ends and the next begins. This module simulates Character Count, Byte Stuffing, and Bit Stuffing techniques.

How It Works

Character Count: Each frame starts with a count field indicating the total number of characters in the frame (including the count field itself). The receiver reads the count, extracts that many characters, and repeats for the next frame.
