🔄 Columnar Transposition Cipher: A permutation cipher that arranges plaintext row-by-row into a grid of numeric column width C, and reads down column-by-column to create ciphertext. Decryption reconstructs the column lengths and reads rows to recover the exact message.

✍️ Input Parameters

Grid column width (integer between 2 and 20, cannot exceed message length).
