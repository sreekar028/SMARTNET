📐 Reference Academic Metric Formulas
Packet Delivery Ratio
PDR = (Recv_pkts / Sent_pkts) × 100%
Measures reliability and end-to-end delivery success rate.
Packet Loss Ratio
PLR = (Drop_pkts / Sent_pkts) × 100%
Measures congestion severity and queue overflow frequency.
Throughput (Kbps)
TP = (Total_Bytes × 8) / (T_stop - T_start) / 1000
Effective network capacity utilized over time.
Average End-to-End Delay
Delay = Σ(T_recv - T_sent) / Recv_pkts
Latency taken for packets to traverse hops.
