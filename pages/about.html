About SMARTNET

Network Performance Analyzer & Security Testing System

🌐 Project Overview

The Network Performance Analyzer and Security Testing System (SMARTNET) is a unified, educational web-based platform engineered to provide deep practical insight into core computer networking principles, transport flow control mechanisms, distributed routing algorithms, traffic policing, and packet-level network diagnostics.

Operating on a shared, centralized organizational topology (comprising Client PCs, Core Routers, Subnet Routers, and an Enterprise Server), SMARTNET eliminates fragmented standalone demos by offering synchronized simulation runs, consistent link metrics, and centralized telemetry in an interactive browser environment.

🎯 Project Objectives

📦
Interactive Framing & Error Detection
Visualize data link layer framing (Character Count, Byte Stuffing, Bit Stuffing) and mathematical binary polynomial division for CRC error verification.
🪟
Flow Control & Retransmission Logic
Simulate sliding window pipelining and Go-Back-N ARQ cumulative acknowledgments, frame loss, timeout backoff, and retransmission mechanisms.
🗺️
Comparative Routing Algorithms
Compute and visualize link-state shortest paths via Dijkstra’s algorithm and distributed routing table exchange and convergence via Distance Vector (Bellman-Ford).
🌳
Broadcast Trees & Congestion Control
Model loop-free broadcast delivery trees and evaluate Leaky Bucket traffic shaping, packet drop thresholds, and buffer policing dynamics.
🔒
Cryptographic Concepts & Security Auditing
Illustrate symmetric and asymmetric encryption transforms, alongside authorized port scanning and security audits with Nmap.
🔬
Deep Packet Inspection & NS2 Analysis
Dissect genuine Libpcap captures, inspect protocol headers, and calculate academic NS-2 simulation metrics (PDR, PLR, throughput, delay).

🎓 Key Learning Outcomes

1. Framing & Error Control
Mastering bit and byte framing delimiters, boundary escape conventions, and cyclic redundancy parity calculations.
2. Pipelined Transport Protocols
Understanding window limits, cumulative versus individual ACKs, timeout retransmission costs, and bandwidth-delay product.
3. Graph Routing Dynamics
Analyzing state relaxation in Dijkstra’s algorithm and distributed asynchronous distance vector table convergence.
4. Traffic Shaping & Buffer Limits
Observing how token and leaky bucket queues regulate bursty inflows into smooth, deterministic outflows to prevent congestion.
5. Security & Protocol Dissection
Inspecting real binary packet payloads, dissecting L2–L7 headers, and evaluating trace delivery ratios (PDR/PLR).
6. Unified Systems Integration
Collaborative full-stack integration connecting distinct network protocols into a single, cohesive web application suite.
